# 有効な契約管理 請求未紐づき一覧と対応方針

作成日: 2026-06-25
対象環境: prod

## 前提

有効な契約管理 `Status__c = Activated` は、請求が紐づいている必要がある。

請求紐づきありの判定:

- 請求 `Invoice__c.ParentContract__c` が契約管理を参照している
- または、契約月次明細 `ContractLineItem__c.RelatedInvoice__c` に請求が入っている

## 対応方針

| 方針 | 対象 | 対応内容 |
|---|---|---|
| 方針A | freee請求Workが取引先まで一致している契約 | freee請求書・請求明細を確認し、契約・対象月・金額が確定できるものだけ契約月次明細 `RelatedInvoice__c` を補完する。複数契約や金額差があるものは業務確認後に更新する。 |
| 方針B | freee請求Workが見つからない契約 | freee請求取込漏れ、取引先名/Freee取引先ID不一致、freee側請求未作成、移行対象外のどれかを確認する。必要に応じてfreee請求Work再取得、取引先紐づけ修正、または請求作成を行う。 |
| 方針C | 契約月次明細がない契約 | 先に契約月次明細を作るべき契約か確認する。作成対象なら契約月次明細を作成し、その後請求紐づけを行う。作成対象外なら契約ステータスや移行対象外理由を明記する。 |

## 次の進め方

1. 方針Aの9件は、freee請求書・請求明細の内容を確認し、契約と対象月が確定できたものから `ContractLineItem__c.RelatedInvoice__c` を更新する。
2. 方針Bの51件は、まずfreee請求Work側に該当請求が存在しない理由を確認する。取引先不一致であれば取引先紐づけを補正し、取り込み漏れであればfreee請求Work再取得を行う。
3. 方針Cの1件は、契約月次明細が必要かを先に判断する。必要であれば契約月次明細作成後に請求紐づけを行う。
