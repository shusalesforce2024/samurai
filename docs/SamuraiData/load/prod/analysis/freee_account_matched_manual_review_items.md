## 次の確認観点

1. freee請求書PDFまたは請求明細で、商品・部署・対象期間を確認する。
2. 請求が複数契約を含む場合は、対象の契約月次明細すべてに同じ請求を紐づける。
3. 金額差が初期費用・オプション・値引き・過去月調整によるものか確認する。
4. 確認後、契約月次明細の `RelatedInvoice__c` を手動またはCSVで更新する。
