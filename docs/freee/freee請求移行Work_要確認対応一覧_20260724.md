## 対応順序

1. 優先度「高」の金額不一致、既存請求明細不一致、商品名類似性不足を確認する。
2. 商品未確定レコードの商品を確定し、再利用できる名称は商品マッピングへ登録する。
3. 契約未確定レコードの請求区分を確認し、Freee請求契約ルールを登録する。
4. Workを再検証し、「反映可能」になったレコードだけ本反映する。
